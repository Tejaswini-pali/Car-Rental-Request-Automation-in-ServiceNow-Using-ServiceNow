# Car Rental Request Automation in ServiceNow

## Project Description

Car Rental Request Automation in ServiceNow is a project that automates car rental requests using Catalog Items, workflows, approvals, and task management. It streamlines the request process and demonstrates ServiceNow automation, configuration, and end-to-end request processing.
